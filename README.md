# Ambition Action Tracker

A lightweight, single-page checklist with 20 practical actions to strengthen performance visibility, deliver measurable results, build leadership trust, and prepare evidence for appraisal and promotion discussions.

## Run locally
Open `index.html` in any modern browser. No build step, package installation, backend, API key, or database is required.

## Features
- 20 actionable checklist items in four themes
- Completion count and progress bar
- Checkbox state saved in the current browser using localStorage
- Responsive layout for desktop and mobile

## Important
Progress is stored only in the browser profile where the page is used. It does not sync across devices or browsers. Clearing browser site data may clear the saved checklist.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. GitHub will provide the published URL after the Pages build completes.
